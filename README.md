# TanStack Query Tasks

A React + TypeScript project demonstrating how to use **TanStack Query** for fetching, caching, searching, filtering, refreshing, and displaying API data.

The project contains three tasks:

- Task 1 — Users List
- Task 2 — Product Explorer
- Task 3 — User Details with Query Key

---

## 🚀 Technologies Used

- React
- TypeScript
- Vite
- TanStack Query
- CSS
- REST APIs
